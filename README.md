# React Calculator App

A simple and responsive **Calculator Application** built using **React.js**. This project performs basic arithmetic calculations and demonstrates React concepts like components, state management, and event handling.

## 🚀 Features

* Basic arithmetic operations (`+`, `-`, `*`, `/`)
* Clear all values (`AC`)
* Delete last input (`DE`)
* Decimal (`.`) support
* Error handling for invalid expressions
* Responsive calculator UI
* State management using React `useState`

## 🛠️ Technologies Used

* React.js
* JavaScript (ES6)
* HTML5
* CSS3
